# Film-Industry-Data-Analysis
End-to-end film industry data analysis project using SQL Server Management Studio and Power BI, exploring box office performance, profitability and industry trends across 4 decades

# Project Overview + Objectives
I've developed a growing interest in film, which has led me to explore movies from different decades, spanning the 1950s to the present day, as well as international cinema.

This interest sparked my curiosity about how the film industry has evolved over time, particularly in terms of audience preferences, box office performance and profitability. I was also interested in examining trends in audience ratings, the production companies behind films, the directors and actors shaping the industry and how box office revenue has changed over the years. More broadly, I wanted to explore how developments such as the rise of streaming platforms and social media may have influenced the industry.

Using movie data spanning four decades (1980–2019), I set out to investigate these trends across a range of attributes, with a particular focus on revenue, profitability and audience ratings. The project combines my personal interest in film with data analytics to examine how the industry has changed and identify interesting patterns and trends over time.

# Dataset
Source: (https://www.kaggle.com/datasets/danielgrijalvas/movies)

Format: CSV

File: Data/movies.csv

# SQL Analysis
SQL Server Management Studio was used to query and analyse the dataset, applying aggregations, joins, common table expressions and window functions to answer various questions, calculate profitability and uncover industry trends.

The SQL queries can be found in Movie Project.sql (https://github.com/AArdh600/film-industry-data-analysis/blob/main/SQL/Movie%20Project.sql).

# Power BI Dashboard 
Developed an interactive Power BI dashboard, using Power Query for data transformation and cleaning, DAX to create custom measures, and incorporating decade-based slicers and visualisations to communicate key findings.

The interactive dashboard can be found at (https://github.com/AArdh600/film-industry-data-analysis/blob/main/Power%20BI/Movie%20Power%20BI%20Project.pbix)
